# CartoRig — Fusion-first 1.0 development

**Development branch:** `release/1.0-rc1-fusion-rewrite`.

**Release status:** NOT certified RC1. This branch uses the 8 November 2026
product specification CR-PS-2.0 and makes no claims of passing tests that
have not been run in DaVinci Resolve Studio 20.

## Product architecture

- **Scene** — one Fusion UIManager window, opened with `CartoRig Scene`
  from the Fusion scripting menu. Hierarchical object Tree, category/group
  organization, context-aware offline search, explicit batch Hide/Show/Lock/
  Delete/Group, Node Editor selection bridge, object registry, read-only
  broken-scene inspection, guarded Recover Copy, and single-window lifecycle.
  All interaction remains subject to actual Resolve-host certification.
- **Control** — native Fusion Inspector parameters exposed by original
  OpenFX objects. Source geometry, independent colors and geo camera.
- **Motion** — an adjacent Inspector page with editable keyframe channels.
  The initial Apply Motion button uses OpenFX host-owned keyframes.
  Native Spline handling must be verified inside Resolve 20.

There is **no Edit-first editor**, no network login, no proprietary
GEOlayers 3 or Map Creator Pro code, and no second animation timeline.

## Building and running

Source build is C++20 with CMake, a pinned ASWF OpenFX 1.4 SDK and Python
standard library only for OFFLINE PACKAGE GENERATION on CI.

CI jobs on Windows and Ubuntu compile the renderer, run C++ and data
regressions and a mock Fusion-Lua host test. The Linux sanitizer job
exercises memory and undefined-behavior checks. Data acquisition happens
only on build runners, from official Natural Earth publisher archives.

The Windows **development** ZIP is generated by CI and includes a compiled
OpenFX bundle, offline data, Scene Lua scripts and a one-click installer.

To install a reviewed development artifact:

1. Close DaVinci Resolve Studio 20.
2. Extract the complete ZIP to a local directory.
3. Double-click `Install-CartoRig.cmd` and approve Windows UAC.
4. Restart Resolve and open a disposable Fusion composition.
5. Choose `Workspace > Scripts > Comp > CartoRig Scene`.
6. Click `Initialize CartoRig Scene` in the one-window UI.

The developer data pack includes official 10m Natural Earth countries,
Admin-1 states/provinces, populated-place points and land polygons.
Countries and states are areas; cities are points, not municipal polygons.

## Release gates — NOT COMPLETED

The product spec requires 60 QA cases, 10 HOST checks, offline 4K image
quality/alpha regression, scene reopen/Undo and real Fusion UI testing.
Those checks have **not** been passed by this build merely because the CI
compiles successfully. Remaining work includes full typography/Label host
verification, geo Route linked-marker Follow Path, native Motion
easing/customized fingerprint handling, anti-meridian polygon seam,
host-level Scene Tree/selection/recovery certification, Spline verification
and final Windows installer QA.

The Scene engineering acceptance ledger is
[docs/SCENE_MILESTONE1_ACCEPTANCE.md](docs/SCENE_MILESTONE1_ACCEPTANCE.md).
It identifies exact simulated proofs and the mandatory real Resolve gates.
Do not interpret test coverage of the Scene as real-host UX approval.

No stable release, automatic merge, or sign-off will occur without the
required evidence. This rewrite branch remains isolated from `main`.

## Troubleshooting

Native plugin errors append to `%TEMP%\cartorig-rc1-error.log`. The
Scene window reports errors without modifying another composition's
selection. Please keep the exact Resolve build, plugin SHA and source
manifest alongside any future host test report.
