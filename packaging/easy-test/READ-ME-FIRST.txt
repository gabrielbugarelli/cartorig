CARTORIG EDIT-FIRST PREVIEW — WINDOWS / DAVINCI RESOLVE STUDIO 20
===================================================================

INSTALL (NO TERMINAL / PYTHON / COMPILER)
1. Close DaVinci Resolve.
2. Extract this package. Double-click Install-CartoRig.cmd and accept Windows UAC.
3. Reopen Resolve Studio 20 and open any existing project and Edit timeline.

CREATE AN ANIMATED CARTOGRAPHIC CLIP
1. Workspace > Scripts > Utility > CartoRig - Create Map
   Inserts a Fusion Composition containing the CartoRig C++ map engine.
2. Place the timeline playhead inside that new map clip, then use:
   - CartoRig - Add Country  (search country name or ISO3; independent color/reveal)
   - CartoRig - Add Route    (select 2 countries; independent animated line)
   - CartoRig - Set Camera  (move to an approximate country focus)
3. Play, save and export using DaVinci Resolve as normal.
   For more advanced work, open Fusion and edit the generated nodes/keyframes.

The interface and script dialogs are English-only.
Countries are searched OFFLINE from the bundled small geo database.
No 51-source Natural Earth pack is required. The full raster library and
city/state search are NOT yet included in this preview.

REAL HOST CERTIFICATION
The previous architecture test established that the CartoRig Overlay can
run inside a Fusion Composition, and a basic camera animation survived
save/reopen/Deliver in a real Resolve 20 test. These NEW country/route
authoring actions, the independent layer camera expressions and this exact
compiled package have NOT YET been accepted on the real Resolve host.
The PR remains draft pending that evidence.

If an action fails, no other project is overwritten. For an error report:
  %TEMP%\CartoRig-Editor-Result.txt
A new Fusion Composition may remain on the timeline if map creation failed.
The older "CartoRig Hybrid Test" script remains available for diagnostics.

CartoRig remains a developer preview, not a finished 1.0 release.
