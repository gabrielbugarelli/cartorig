CARTORIG 1.0 — UNIFIED AUTHORING PREVIEW (WINDOWS)
===================================================

STATUS: DEVELOPMENT / REAL RESOLVE STUDIO 20 ACCEPTANCE REQUIRED.
Do not label this build CartoRig 1.0 stable.

INSTALLATION
1. Close DaVinci Resolve Studio 20 completely.
2. Extract the package to a normal directory.
3. Double-click Install-CartoRig.cmd and approve administrator access.
4. Reopen Resolve 20 and go to the Edit page.
5. Workspace > Scripts > Utility > CartoRig - Editor.

THE SINGLE AUTHORING WINDOW
- Create map: inserts a neutral Fusion Composition with OpenFX rendering.
- Scene selector: select the CartoRig clip explicitly before editing.
- Find: search by natural place name, choose type when ambiguous.
- Add Region: adds an independent country/state polygon, when available.
- Add Marker / Label: adds a georeferenced point with basic text.
- Focus Camera: updates a static camera, with NO implicit keyframes.
- Animate Camera: explicitly requests Fusion spline keyframes.
- Objects: select, style, show/hide, or delete an existing object.
- Base Map: change land, ocean or border color using the same HEX field.
- Route: choose origin and destination; states require explicit lon/lat.
- Reveal Route: explicitly requests Fusion spline keyframes.
- No default Brazil–Venezuela animation, no ISO3 fields in the UI.

OFFLINE DATA
- The small bundled country geometry is available without extra downloads.
- State and city search REQUIRES a locally installed Natural Earth pack with:
  %LOCALAPPDATA%\CartoRigNative\NaturalEarth\vector\catalog.sqlite
  %LOCALAPPDATA%\CartoRigNative\NaturalEarth\vector\natural_earth_vector.gpkg
  %LOCALAPPDATA%\CartoRigNative\NaturalEarth\vector\supplements.gpkg
- The installer does not download geographical data or contact services.
- Not all official raster sources have been acquired or certified yet.
- A city point is NOT a municipal boundary. If geometry is absent, the
  operation must fail instead of inventing a polygon.
